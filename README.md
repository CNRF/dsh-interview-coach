# dsh-interview-coach

语音面试助手 · Voice interview coach for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

选择技术栈与参考资料，按目标职级标准进行语音模拟面试：自我介绍 → 语音出题 → 语音作答 → 逐题百分制打分 → 导出面试记录文档。

## 功能

- **五种练习模式**：模拟面试（自我介绍→出题→追问→打分，不给答案）/ 背八股（围绕一个技术主题刷通用高频面试题，不结合个人项目）/ 简历押题（简历+JD 押高概率题）/ 场景题（系统设计、故障排查）/ 刷力扣（Hot 100 题库，思路+代码+复杂度分析）
- **可配置面试**：技术栈、目标职级（中级/高级/资深/架构师）、题量、面试风格、考察配比、目标岗位 JD
- **参考资料**：可选简历/笔记文件夹，开始前由 LLM 预摘要后用于出题，不硬编码任何个人信息
- **模型可选**：默认跟随 Harness 默认模型；也可在配置页从当前 DSH 已注册的模型中挑选，**支持模糊查询**（输入模型名/id/provider 过滤，回车选中第一个），选择即时生效并持久化
- **语音交互**：本地 SenseVoice 语音识别（免费、离线）；面试官朗读可选系统音色（离线）或 Edge TTS 在线音色（晓晓/云健/云希等，更自然），支持语速/语调调节与试听
- **场景题深挖**：场景题可从简历/项目笔记改编，职级决定问题深度与追问节奏（中级最多 1 轮追问 → 架构师最多 3 轮），追问链结束后才展示讲解与参考答案
- **逐题评分**：准确性 / 深度 / 表达 / 完整性四维度各 25 分，百分制，附总评与改进建议
- **答题前参考回答**：答不上来时主动点「💡 参考回答」，即时生成**答题提纲 + 可直接复述的参考答案 + 常见坑**；按题缓存、不自动弹出、不影响本题评分
- **讲解与参考答案**：练习模式下每题作答后给出知识讲解与可直接复述的参考答案（力扣题含代码实现）
- **多次作答对比**：支持重新作答，历次得分与回答并列对比，不覆盖旧记录
- **断点续面**：每次作答后自动存档，关闭页面后可继续
- **记录导出**：输出目录下生成 `面试记录.md`、`面试记录.docx`、`scores.json`、`transcript.md`；历史记录支持单条 JSON 导出
- **历史沉淀**：历史列表支持**按练习类型筛选**、**多选导出/删除**；导出为可读的 Markdown（含逐题得分、改进建议、讲解与参考答案），也可导出单场记录；得分趋势图

力扣题库数据改编自 [codingayice/dsh-interview](https://github.com/codingayice/dsh-interview)（MIT），题目列表来自 [LeetCode 热题 100](https://leetcode.cn/studyplan/top-100-liked/)。Edge TTS 的 Sec-MS-GEC v2 令牌算法移植自 [MsEdgeTTS](https://github.com/Migushthe2nd/MsEdgeTTS)（MIT）。Edge TTS 为非官方接口，稳定性不保证，失败时自动回退系统音色。

## 依赖

- DeepSeek Harness（本插件运行于其插件体系）
- 官方 **Voice Input** 插件包（提供本地 SenseVoice 语音识别）；未启用时插件会给出引导
- Harness 已配置默认模型（出题与评分复用该连接，无需额外配置）

## 安装

在 DeepSeek Harness 插件管理中安装 npm 包 `dsh-interview-coach`，或本地目录安装本仓库。

## 使用

1. 侧边栏点击麦克风图标打开面试助手
2. 确认「运行环境自检」全部通过（模型 / 语音 / 输出目录）
3. 选择练习模式，填写配置，选择参考文件夹（可选）与输出目录，开始练习
4. 点击「开始回答」录音，说完点「回答完毕」，确认识别文字后提交
5. 答不上来时点「💡 参考回答」查看提纲与完整参考答案；点评后可重新作答对比
6. 结束后自动生成报告与面试记录文档

> 详细的配置建议、各模式适用场景和练习技巧见 **[使用指南](docs/使用指南.md)**。

## 数据位置

- 面试记录与通用设置保存在用户级目录 `~/.dsh/dsh-interview-coach/`（`interviews/`、`settings.json`、`cache/`），可用环境变量 `DSH_INTERVIEW_COACH_HOME` 覆盖
- 该目录与端口、profile、应用重启无关，历史记录和已选的参考/输出目录不会因重启丢失
- 面试报告文档写入你在配置页选择的输出目录

## 排障

- **插件面板消失 / 接口 404**：多为宿主重启后 `cordis.patch.yml` 中的插件行被第三方工具重写。在插件管理中对 `dsh-interview-coach` 执行一次卸载再安装即可恢复（数据不受影响）
- **改了 client.js 界面没更新**：宿主只在启动时读取客户端代码，需要完全退出并重启 DeepSeek Harness（刷新页面不够）；或运行 `pnpm run dev:web` 启用 HMR
