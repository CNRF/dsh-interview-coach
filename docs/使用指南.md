# 使用指南：怎么用这个插件练得更有效

> 配套文档：[项目经历模板](./项目经历模板.md)

---

## 一、第一次使用：先做环境自检

打开插件后面板顶部「运行环境自检」，确认三项都通过：

| 检查项 | 不通过怎么办 |
|---|---|
| 模型连接 | 去 Harness 设置配置默认模型；或在「面试模型」里手选一个可用 provider |
| 语音识别 | 在插件管理启用「Voice Input」插件包；未下载运行时点「下载并准备」（首次约 1~2 分钟） |
| 输出目录 | 在配置页选择目录（面试记录会写到这里） |

> 只想打字不想说话？完全可以——录音只是可选输入，直接在回答框输入即可。

## 二、五种模式怎么选

| 模式 | 适合什么时候用 | 关键配置 |
|---|---|---|
| **模拟面试** | 面试前 1~2 天全流程模拟，检验真实水平 | 技术栈 + 职级 + 风格（压力面记得选）+ JD |
| **背八股** | 每天碎片时间刷一个主题的**通用高频题**（不结合你的项目经历） | 主题（JVM / MySQL / Redis / 并发…） |
| **简历押题** | 有明确目标岗位时，押最可能被问的问题 | 必选简历文件夹 + JD |
| **场景题** | 练系统设计、故障排查、项目复盘 | 参考文件夹（自动提取项目）或手填场景 |
| **刷力扣** | 面试里的手撕代码环节 | 选语言，从 Hot 100 里挑题 |

## 三、配置项怎么填

### 技术栈 vs 练习主题（不用重复填）
- **模拟面试 / 简历押题**：填技术栈，写具体一点，`Java 后端（Spring Boot / Dubbo / MySQL / Redis）` 比 `Java` 更能生成针对性题目。
- **背八股 / 场景题**：只填**练习主题**即可（如 `JVM`、`Redis 缓存穿透`），主题本身就是技术方向，技术栈会自动沿用主题。
- **刷力扣**：只需选编程语言。

### 目标职级（决定问题深度，比题量重要）
- 中级：概念与应用为主，源码级较少涉及
- 高级：原理机制 + 生产实践
- 资深：源码级实现、底层机制、量化与权衡
- 架构师：架构权衡、技术演进、组织影响

> 建议：**按目标岗位定级**，不要按自己当前职级。练完再换一档对比，能看出差距。

### 题量
只影响问题数量，不影响深度。时间紧选 5 题，完整模拟选 10~15 题。

### 参考文件夹（能显著提升质量的配置）
- 选**包含简历和项目经历**的文件夹（写法见[项目经历模板](./项目经历模板.md)）
- **只有模拟面试 / 简历押题 / 场景题**会读取并摘要参考文件夹；背八股和刷力扣与个人经历无关，不会读取
- 场景题模式会自动从文件夹提取**项目清单**，按「项目 × 考察角度」轮换出题
- 首次解析要做资料摘要，约 1~2 分钟，之后有缓存
- 解析失败会显示原因，不会自动重试；可修正文件夹后手动点「重新解析」

### 面试风格
- 常规：氛围友好，追问少
- 压力面：追问犀利，专挑漏洞
- 项目深挖：围绕项目经历持续挖设计动机和取舍

### 模型
默认跟随 Harness 默认模型。想对比不同模型的出题质量，可以在「面试模型」里切换（支持模糊查询，如输入 `k3`、`glm`、`deepseek`）。建议出题和评分用同档位偏强的模型。

## 四、练习中的技巧

1. **答不上来别硬编**：点「💡 参考回答」看提纲 + 完整答案，按你当前职级生成。看完再答一遍，比卡住不动有效。
2. **先用语音说，再改文字**：语音逼你像真实面试那样组织语言；识别错字在提交前改掉。
3. **重新作答**：每题点评页可「重新作答」，历次得分会并列对比——同一道题答两遍，进步最明显。
4. **看清追问问的是「角度」不是「重复」**：追问通常来自你没讲透的点，回答前先判断它想验证什么。
5. **场景题追问链**：职级越高追问越多（中级 1 轮 → 架构师 3 轮），别指望一轮过关。

## 五、练完之后

- **报告**：结束练习自动生成到输出目录，含 `面试记录.md`、`面试记录.docx`、`scores.json`、`transcript.md`
- **历史记录**：支持按类型筛选、多选导出 Markdown（含逐题得分、改进建议、讲解、参考答案）、多选删除
- **得分趋势**：完成两场以上后，历史页展示趋势图，用来验证某类题的进步是否真实

## 六、FAQ

**Q：为什么生成的题目和我的项目对不上？**
检查参考文件夹里是否有明确写出项目名称和你的职责。文件名带「简历 / 项目 / 经历」会被优先读取。

**Q：语音识别不准怎么办？**
技术术语中英混说容易识别偏。提交前直接改文字即可，评分按修改后的文本。

**Q：面试记录存在哪里？**
通用设置与历史在 `~/.dsh/dsh-interview-coach/`；报告文档写入你配置的输出目录。

**Q：改了界面没生效？**
客户端代码只在应用启动时加载，需要完全退出 DeepSeek Harness 再打开（刷新页面不够）。
